# Переносимое игровое ядро

План: отсутствие обращений к DOS, BIOS и портам аппаратуры. Целевой ассемблер 8086/8088; 16-битные целые и фиксированная точка. Состояние обновляется дискретным тиком; рендеринг может пропускать кадры без изменения логики.

Первый вертикальный срез: движение игрока, один противник, снаряды, разрушение кирпича, обработка победы/поражения. **Пока не реализован.**
