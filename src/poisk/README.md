# Нативный «Поиск-1»

Здесь появятся драйверы встроенного видео/клавиатуры и самостоятельный загрузчик для раннего базового Poisk-1 без DOS/дисковода. Не подменяйте Poisk-1 эмуляцией IBM CGA: архитектура иной видеоподсистемы подтверждена техническими источниками.

Формат кассеты, BIOS entry points и возможность запуска по ревизиям **ещё не проверены**; нельзя распространять непроверенный .CAS как рабочий. ROM/BIOS образы не включать в репозиторий.
