# Формат уровня v0

Ровно 13 строк по 13 ASCII-символов, без BOM, без пробелов. Обозначения:

- `.` — пусто
- `#` — кирпич (разрушаемый)
- `X` — бетон (неразрушаемый обычным снарядом)
- `~` — вода (препятствие)
- `T` — лес (скрытие)
- `P` — начало игрока (одна клетка)
- `E` — потенциальная точка появления противника (не менее одной)
- `B` — база (ровно одна)

Координаты и логика — 13×13 на всех видеоадаптерах. Физическое изображение/масштаб зависят от драйвера; сетка 13×13 **не подразумевает** клетки 16 px высотой на CGA 200 строк. Формат прототипный: непроходимость и спавн уточняются после вертикального среза.

Проверка: `python3 tools/validate_map.py assets/maps/level01.map`.
