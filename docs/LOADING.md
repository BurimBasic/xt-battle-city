# Загрузка: DOS и нативный «Поиск-1»

## DOS XT

* Простая сборка `.COM` (`org 0100h`), исходно минимальная зависимость от DOS.
* Зафиксировать PSP, начальный/конечный RAM, выделение стека; не обращаться к памяти выше доступного сегмента.
* Наблюдаемая диагностика `XTINFO.COM` — только DOS; не должна считаться proof-of-game.
* Автовыбор видео и звука внедрять после получения собственных backend.

## «Поиск-1» без расширений

* Ранние базовые платы **не имеют дисковода/контроллера**, значит MS-DOS не может быть единственным механизмом загрузки.
* Исследовать штатную кассетную загрузку, ROM BIOS и адрес запуска для конкретных ревизий; подготовить генератор проверяемых образов и native entry point без DOS.
* Кассетный формат/механика могут различаться; до подтверждения в MAME **никаких обещаний рабочего .CAS**.
* Образ должен загружаться в 96-КБ программную память без затирания ROM/VRAM и при этом оставлять стек/буферы.
* Перед каждым релизом документировать результат MAME и, по возможности, реального компьютера.

## Условия распространения

Не включать BIOS-ROM, DOS и проприетарные образы в исходный репозиторий. Пользователь законно предоставляет ROM для локальной эмуляции. Готовые файлы сборки включают **только авторский код игры/загрузчика**.
