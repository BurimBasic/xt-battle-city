# Паспорт проекта

## Формулировка

XT Battle City — новая, свободная, маленькая и быстрая игра про танки: ощущения классической 8-битной аркады на **оригинальных 8088 4,77 МГц** и **базовом «Поиск-1»**. Это не порт чужого ROM и не попытка эмулировать NES на XT.

## Для чего

1. Проверить практический потолок анимации, искусственного интеллекта, звука и оптимизации на 8088.
2. Дать ретросообществу свободную игру с реальной поддержкой специфического советского оборудования.
3. Сохранить полностью воспроизводимую цепочку: исходники → сборка → эмулятор → замеры → образ для запуска на железе.
4. Отработать документированную библиотеку ввода, видео и звука для будущих 8088-игр.

## Продуктовая цель

Пользователь загружает игру на поддерживаемой машине и может пройти **не менее одного полноценного уровня** с отзывчивым управлением, препятствиями, противниками, жизнью базы и победой/поражением. Дальнейшая цель — набор уровней и 2 игрока.

## Обязательное

- Native «Поиск-1» ранней ревизии без обязательной памяти/дисковода, после изучения штатной загрузки.
- DOS IBM XT 4,77 МГц с CGA.
- EGA/VGA/Hercules: отдельные драйверы, одинаковый gameplay.
- PC Speaker без карты и OPL2/AdLib при наличии.
- Весь игровой код без x86 286+, без FPU; видеозависимость только в драйвере.
- Никаких копий коммерческих спрайтов, звуков, уровней, музыки или ROM.

## Успех / метрики

- 1 завершённый уровень; никаких критических потерь управления или игровых тиков.
- Начальная цель **12–15 FPS** на IBM 8088 4,77 МГц с CGA, **требует замера**; при необходимости адаптивная отрисовка без ускорения логики.
- На «Поиск-1» раннего типа общий working set в пределах реально доступной памяти, с запасом. Без скрытого требования расширения до 256–640 КБ.
- AdLib отсутствует → игра без ошибок использует Speaker.
- Видеодрайвер недоступен → понятное сообщение и выход без зависания.
- Билд из публичных исходников; автоматизированные sanity tests и воспроизводимые отчёты замеров.

## Ограничения

Поиск аппаратных различий и кассетного протокола является **открытым исследовательским этапом**. Пока он не завершён, нативную совместимость обещать нельзя.
