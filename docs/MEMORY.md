# Бюджет памяти и скорость

## Ранний «Поиск-1»

По имеющимся описаниям: 128 КБ RAM физически, ~32 КБ — видеопамять, около **96 КБ** доступно коду и данным. Это **потолок аппаратной конфигурации**, а не гарантированный объём для приложения после конкретного загрузчика/BIOS.

Черновой бюджет *для измерения* (внутри доступного ОЗУ; не сумма установленной RAM):

| Подсистема | Плановый лимит |
|---|---:|
| Код/драйверы/константы | 32 КиБ |
| Уровень/состояние/ИИ/пули | 8 КиБ |
| Спрайты/тайлы в компактном виде | 12 КиБ |
| Стек, временные буферы, таймеры | 4 КиБ |
| Резерв под BIOS/загрузчик/непредвиденное | 40 КиБ |
| **Всего** | **96 КиБ** |

Числа ориентировочные, лимит на ROM/BIOS ещё надо проверить на эмуляторе; **уже на первом тесте** замерить фактические регионы памяти. Отсутствие полноэкранного offscreen 16/64-КБ буфера — правило для базовой ветки. В DOS-ветке RAM-бюджет пересчитывается с учётом резидентного DOS и PSP.

## Производительность

- CPU baseline: 8088 **4,77 МГц** (IBM), Poisk-1 отдельно **5 МГц**.
- Исходный ориентир 12–15 FPS CGA; **никаких утверждений о достигнутых FPS** до теста.
- Логика фиксированным дискретным тиком; кадры можно пропускать, не ускоряя/замедляя физику.
- Не перерисовывать всё поле без необходимости; dirty tiles/rects, предварительные битмаски, проверка цены CGA VRAM accesses.
- Спрайты и уровни распаковывать малыми блоками; не использовать framebuffer «про запас».
- Тестировать тяжёлые сцены (враги, выстрелы, одновременно разрушенные тайлы), чтобы не ориентироваться только на заставку.

## v0.6 CGA pixel sprite footprint

The DOS `.COM` grows to approximately 29KiB because 32 moving sprite patterns include four shifted 12x10-byte alpha/color variants each (~15KiB). This is deliberate to reduce runtime pixel-shift work on 8088. There is no full-screen offscreen buffer. The current original Poisk-1 96KiB budget is still **an unverified design goal**, not a verified compatibility claim. Its native backend may need tighter sprite compression/decompression and must be measured separately.
