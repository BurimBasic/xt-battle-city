# Этапы разработки (в порядке риска)

Ни один этап не отмечен выполненным без test evidence.

| Этап | Результат | Проверка готовности |
|---|---|---|
| M0 — репозиторий | исходники, документация, CI, диагностика | `make test` зелёный; код публично доступен после публикации |
| M1 — база Poisk | разобраны BIOS/96-КБ RAM/клавиатура/видео/кассета | минимальный native hello без DOS и дисковода в MAME `poisk1` |
| M2 — DOS XT CGA | работающий рендерер карты и управление | 8088/4,77 86Box, без 286+ и лишней памяти |
| M3 — игровой вертикальный срез | игрок, выстрел, кирпич, 1 противник, база | один играбельный законченный уровень |
| M4 — Poisk gameplay | общий core под native загрузчиком | тот же уровень на базовом Poisk без обязательного расширения |
| M5 — видеодрайверы | EGA, VGA, Hercules | каждый работает с идентичной логикой и управлением |
| M6 — звук | Speaker + обнаружение/вывод OPL2 | без карты безопасный fallback, с картой проверенный FM |
| M7 — оптимизация | стабильное управление, замеры FPS и RAM | отчёт на худших тестовых сценах 8088 4,77 и Poisk 5 |
| M8 — release | авторские уровни/арт, документация, архивы | воспроизводимая сборка и тест-матрица; 1.0 после приёмки |

## Порядок приоритетов

Совместимость с минимальным оборудованием > играбельность > стабильное время кадра > объём эффектов. Никакой фичи EGA/VGA/OPL2, если она ломает Poisk/CGA baseline. «Двое игроков» после M3/M4 и только если позволяет бюджет CPU/RAM.
