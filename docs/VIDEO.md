# Видеодрайверы и масштаб

| Backend | Режим | Технические особенности |
|---|---|---|
| CGA | 320×200, 4 цвета | 2 bit/pixel; чересстрочная банковая организация (чётные/нечётные строки), конкуренция с CPU за память |
| EGA | 320×200, 16 цветов | четыре видеоплоскости; запись через регистры plane/write-mask |
| VGA | 320×200, 256 цветов | цепочечный Mode 13h; вывод 64 КБ на 8088 может быть дорогим |
| Hercules | 720×348, 2 цвета | монохром; особое разбиение видеопамяти; отдельные паттерны материалов |
| Poisk-1 | встроенное CGA-подобное | видеорегистры/эмуляция текста не эквивалентны IBM CGA; отдельная проверка/драйвер |

**Не смешивать качество и возможность игры.** VGA может оказаться медленнее CGA на 8088. Одинаковая логика и карта, но разные тайлы/цветность/спрайты. При старте DOS — автоопределение поддерживаемого режима, ручной выбор позже (`/CGA`, `/EGA`, `/VGA`, `/HERC`). Для native Poisk-1 — отдельная сборка/конфигурация.

13×13 × 16 px = 208 px по вертикали и **не помещается** в CGA 200 строк. Не копировать пиксель-в-пиксель геометрию NES. Первый макет: тайл 14×14 = 182×182 px, оставшееся пространство для полей/счёта. Позже изучить варианты тайла/времени рендера, не меняя игровую сетку.

План рендера: заранее упакованные тайлы → dirty rectangles/dirty cells → пересчёт только изменённых участков. Полноэкранный double buffer в памяти **не обязателен и запрещён как требование к базовому Poisk**. Для Hercules делать визуально различимые монохромные штриховки.

Прежде чем объявлять поддержку, выполнить скриншот и FPS-тест каждого backend в 86Box; Poisk-1 отдельно в MAME. Видеоотсутствие/неподдерживаемое железо — безопасный отказ.


## v0.19 — проверка реального состояния драйверов (SLOW1, 2026-11-10)

| Адаптер DOSBox-X | /TEST | Что реально проверено | Готовность native |
|---|---|---|---|
| CGA | **PASS** | штатный mode 4, 320×200×4, B800h | **Да, DOS** |
| EGA | **PASS** | только совместимость с CGA mode 4 | **Нет**, EGA 320×200×16 требует A000h и четырёх плоскостей |
| VGA | **PASS** | только совместимость с CGA mode 4 | **Нет**, VGA mode 13h требует собственного 256-цветного рендера |
| Hercules | **FAIL** | CGA mode 4/B800h недоступен как на CGA | **Нет**, нужен режим 720×348, B000h и отдельный битовый вывод |
| «Поиск-1» | не проверялось | отдельные видеорегистры и нативная загрузка | **Нет**, требуется собственный драйвер |

Тесты EGA/VGA подтверждают успешную *работу CGA-совместимого DOS-кода*,
а не наличие родных EGA/VGA видеорежимов. DOSBox-X `machine=ega`,
`machine=vga`, `machine=hercules`; неизменный `TANKS.COM /TEST`.
Проверить изображение глазами и на физическом ISA-адаптере всё ещё нужно.
Никакого автоматического выбора несуществующего backend в этом релизе нет.

Палитра mode 4 выбирается через `C` и регистр 3D9h. Выбор удерживается в
**RAM до выхода из программы**, восстанавливается после BIOS `INT10h`
mode reset и не зависит от `.CFG`, `.INI`, дисковода, CMOS или кассеты.
На холодной загрузке без внешнего носителя выбор не переживает выключение.
